# Eastern Sun Resurrected archive sources

Sanctuary Atlas keeps the Eastern Sun Resurrected archive separate from its standard D2R references.

The packaged data is parsed from the public ESR 2.31 reference pages:

- https://d2esrdb.github.io/Eastern_Sun_Resurrected/runewords.htm
- https://d2esrdb.github.io/Eastern_Sun_Resurrected/Eastern%20Sun%20Resurrected%20Cube%20Recipes.html

The mod's public source and documentation are maintained at https://github.com/CelestialRayOne/Eastern_Sun_Resurrected and https://easternsunresurrected.com/.

These references can change with the mod. RefreshEsrArchive.ps1 rebuilds `esr-archive.xml` from the listed public reference pages before making a new Sanctuary Atlas content release.
